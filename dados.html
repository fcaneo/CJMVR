Lanzador de dados virtual: D4, D6, D8, D10, D12, D20

Si juegas D&D, Pathfinder, Vampiro, Call of Cthulhu o cualquier juego de rol, sabes el problema: nunca tienes suficientes dados, te falta justo el D8, o el D20 lo perdió alguien la sesión pasada. Lo mismo pasa con muchos juegos de mesa que requieren múltiples dados (Catan, King of Tokyo, Yahtzee, Dungeon Roll). Este lanzador resuelve eso: tienes todos los dados disponibles, en cualquier cantidad (hasta 10 a la vez), con suma automática y un historial de las tiradas.

Funciona en el navegador, sin descargas ni registros. Para sesiones de rol largas conviene tenerlo abierto en una pestaña dedicada — es más rápido que andar buscando dados físicos cada cinco minutos.

Cómo funciona

  1. Elige el tipo de dado (D4, D6, D8, D10, D12 o D20).
  2. Elige cuántos quieres tirar (1 a 10).
  3. Toca "Tirar" y aparecen los resultados con la suma total.
  4. El historial guarda las últimas tiradas para que puedas revisar.

Preguntas frecuentes

¿Es realmente aleatorio?

Sí. Usa el generador aleatorio del navegador, igual que un dado físico.

¿Sirve para D&D y juegos de rol?

Sí, está pensado para eso. Cubre todos los dados estándar de RPG.

¿Puedo tirar 3d6+2 o expresiones tipo "20+5"?

No, esto es un lanzador simple. Tiras N dados de un mismo tipo y haces el cálculo aparte si necesitas modificadores.

¿Funciona offline?

Una vez cargada, sí.

¿Guarda algo?

Solo el historial reciente en tu navegador. Nada en servidor.

¿Puedo usarlo en torneo?

Para apuestas o competencias formales, mejor usa dados físicos certificados. Para una sesión casera, sirve perfectamente.
